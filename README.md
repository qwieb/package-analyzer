# Package Dependency Analyzer

Инструмент для визуализации графа зависимостей пакетов Python (pip).

## Описание
Программа анализирует зависимости указанного пакета и строит граф зависимостей (BFS). 
Разработано в рамках дисциплины "Конфигурационное управление" (Вариант 6).

## Функции и настройки
Программа настраивается через файл `config.ini`:
* `package_name` — имя анализируемого пакета.
* `repo_url` — URL-адрес репозитория (или путь к тестовому JSON).
* `test_mode` — режим работы с тестовым репозиторием (True/False).
* `output_image` — имя файла для сохранения графа.
* `ascii_tree` — режим вывода в виде ASCII-дерева (True/False).
* `max_depth` — максимальная глубина анализа зависимостей (целое число).

## Реализованные этапы
* **Этап 1:** Парсинг INI-файла и валидация всех параметров.
* **Этап 2:** Получение прямых зависимостей пакета через API PyPI (без использования pip и сторонних библиотек).
* **Этап 3:** Построение графа зависимостей с помощью алгоритма BFS (поиск в ширину) без рекурсии, с поддержкой ограничения глубины и обработкой циклических зависимостей.
